How it works

Three steps. One gift.

Fund a card, share the link, and they claim it. Arc escrow holds the USDC the whole way, and nothing moves until the right code is used.

01 / CREATE

Create & fund

Choose an amount, add a custom message, and fund it with USDC. A unique code is made in your browser.

02 / SHARE

Share the code

The USDC waits in escrow on Arc. Send the code by email, WhatsApp, Telegram or X.

03 / CLAIM

Receiver claim

Receiver pastes any wallet address. Tessera pays the gas, and the code can never be used twice.

Features

One mechanism, executed flawlessly.

A focused, gasless claim system that lets the gift speak for itself. No account creation or wallet connection needed.

Single-use codes

Each code redeems exactly once. The state lives on Arc - a second try can't claim it again.

Gasless claims

Recipients paste any address: MetaMask, Rabby, even a fresh wallet. The sender covers the small network fee up front.

Refund after 30 days

If nobody redeems the code within 30 days, the sender can take the USDC back from the contract.
